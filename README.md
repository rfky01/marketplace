# 🛒 Campus C2C Marketplace

Aplikasi marketplace Consumer-to-Consumer (C2C) yang dirancang khusus untuk memfasilitasi mahasiswa dalam melakukan transaksi jual beli barang bekas di lingkungan kampus secara aman dan terpercaya.

##  Fitur Utama

- **Autentikasi Pengguna:** Registrasi dan verifikasi akun yang aman menggunakan integrasi OTP via WhatsApp.
- **Manajemen Produk:** Pengguna dapat dengan mudah mengunggah, mengedit, dan menghapus daftar barang bekas yang ingin dijual.
- **Pencarian & Filter:** Sistem pencarian barang yang intuitif berdasarkan kategori dan kriteria lainnya.
- **Interaksi Pengguna:** Memfasilitasi komunikasi langsung antara penjual dan pembeli.
- **Dokumentasi API Terintegrasi:** Tersedia dokumentasi API interaktif menggunakan Swagger (L5-Swagger).

##  Tech Stack

Proyek ini dibangun menggunakan teknologi berikut:

- **Backend:** Laravel
- **Frontend:** React
- **Database:** PostgreSQL
- **Environment & Deployment:** Docker 
- **Layanan Pihak Ketiga:** Fonnte API (Untuk layanan OTP WhatsApp)
